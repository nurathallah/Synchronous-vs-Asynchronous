# Materi JavaScript Asynchronous ## 1. Callback Function dan Callback Hell ### Pengertian Callback Function adalah fungsi yang dikirim sebagai argumen ke fungsi lain dan akan dipanggil setelah suatu proses selesai dijalankan. Callback merupakan salah satu cara pertama yang digunakan JavaScript untuk menangani proses asynchronous. ### Penjelasan Pada proses asynchronous, JavaScript tidak perlu menunggu suatu pekerjaan selesai sebelum menjalankan kode berikutnya. Sebagai gantinya, JavaScript akan menjalankan callback ketika proses tersebut telah selesai. Meskipun sederhana, penggunaan callback yang terlalu banyak dan bersarang dapat menyebabkan Callback Hell, yaitu kondisi ketika kode menjadi panjang, sulit dibaca, dan sulit dipelihara. ### Penggunaan * Menjalankan fungsi setelah proses selesai. * Mengatur proses asynchronous. * Digunakan pada event, timer, dan operasi I/O. ### Cara Menjalankan Buat fungsi utama yang menerima callback sebagai parameter, kemudian buat fungsi callback yang akan dipanggil. Setelah itu jalankan file menggunakan browser atau Node.js. --- # 2. Promise: Konsep dan Cara Membuatnya ### Pengertian Promise adalah objek di JavaScript yang digunakan untuk menangani proses asynchronous dan mewakili hasil yang akan tersedia di masa mendatang. ### Penjelasan Promise dibuat untuk menggantikan callback yang terlalu kompleks. Promise memiliki tiga keadaan, yaitu **Pending** (masih diproses), **Fulfilled** (berhasil), dan **Rejected** (gagal). Dengan Promise, kode menjadi lebih mudah dibaca dan lebih terstruktur. ### Penggunaan * Mengambil data dari API. * Membaca file. * Menjalankan proses asynchronous lainnya. ### Cara Menjalankan Buat Promise menggunakan `new Promise()`, kemudian gunakan `resolve()` jika berhasil dan `reject()` jika gagal. Hasilnya diproses menggunakan `.then()` dan `.catch()`. --- # 3. Promise: then(), catch(), dan finally() ### Pengertian `then()`, `catch()`, dan `finally()` adalah metode yang digunakan untuk menangani hasil dari Promise. ### Penjelasan * **then()** digunakan ketika Promise berhasil. * **catch()** digunakan ketika Promise mengalami kesalahan. * **finally()** selalu dijalankan setelah Promise selesai, baik berhasil maupun gagal. Metode-metode ini membuat penanganan hasil Promise menjadi lebih mudah dibandingkan menggunakan callback. ### Penggunaan * Mengolah data hasil Promise. * Menangani kesalahan. * Menjalankan proses penutup seperti menyembunyikan loading. ### Cara Menjalankan Buat Promise, lalu panggil `.then()`, `.catch()`, dan `.finally()` sesuai kebutuhan. --- # 4. Promise.all(), race(), allSettled(), dan any() ### Pengertian Keempat metode ini digunakan untuk mengelola beberapa Promise secara bersamaan. ### Penjelasan * **Promise.all()** menunggu semua Promise berhasil. * **Promise.race()** mengambil Promise yang selesai paling cepat. * **Promise.allSettled()** menunggu seluruh Promise selesai tanpa memperhatikan berhasil atau gagal. * **Promise.any()** mengambil Promise pertama yang berhasil. Metode-metode ini sangat berguna ketika aplikasi menjalankan banyak proses asynchronous sekaligus. ### Penggunaan * Menjalankan beberapa permintaan data. * Menggabungkan hasil beberapa Promise. * Memilih hasil Promise tercepat. ### Cara Menjalankan Buat beberapa Promise kemudian jalankan salah satu metode sesuai kebutuhan. --- # 5. Promise.withResolvers (ES2024) ### Pengertian Promise.withResolvers() adalah fitur baru pada JavaScript ES2024 yang menghasilkan Promise beserta fungsi `resolve` dan `reject` secara terpisah. ### Penjelasan Sebelumnya, fungsi `resolve` dan `reject` hanya bisa digunakan di dalam constructor Promise. Dengan fitur ini, keduanya dapat digunakan di luar Promise sehingga penulisan kode menjadi lebih sederhana dan fleksibel. ### Penggunaan * Membuat Promise yang lebih mudah dikelola. * Digunakan pada aplikasi yang memiliki banyak proses asynchronous. ### Cara Menjalankan Panggil `Promise.withResolvers()`, kemudian gunakan `resolve()` atau `reject()` ketika diperlukan. --- # 6. Async dan Await di JavaScript ### Pengertian Async dan Await adalah fitur JavaScript yang digunakan untuk menjalankan Promise dengan sintaks yang lebih sederhana dan mudah dipahami. ### Penjelasan Keyword **async** digunakan untuk membuat fungsi asynchronous, sedangkan **await** digunakan untuk menunggu Promise selesai sebelum melanjutkan ke baris berikutnya. Dengan cara ini, kode terlihat seperti program biasa meskipun berjalan secara asynchronous. ### Penggunaan * Mengambil data dari API. * Membaca database. * Menggantikan penggunaan `.then()` yang panjang. ### Cara Menjalankan Tambahkan keyword `async` pada fungsi, kemudian gunakan `await` saat memanggil Promise. --- # 7. Error Handling di Async Function ### Pengertian Error Handling adalah proses menangani kesalahan yang terjadi pada fungsi asynchronous. ### Penjelasan Kesalahan pada Promise dapat menyebabkan program berhenti jika tidak ditangani. Oleh karena itu digunakan blok `try...catch` agar program tetap berjalan dan dapat memberikan informasi mengenai kesalahan yang terjadi. ### Penggunaan * Menangani kesalahan jaringan. * Menangani kesalahan server. * Mencegah aplikasi berhenti secara tiba-tiba. ### Cara Menjalankan Letakkan kode yang berpotensi menghasilkan error di dalam blok `try`, kemudian tangani kesalahan pada blok `catch`. --- # 8. Event Loop dan Cara Kerjanya ### Pengertian Event Loop adalah mekanisme JavaScript yang mengatur kapan kode asynchronous dijalankan. ### Penjelasan JavaScript menggunakan satu thread utama untuk menjalankan program. Ketika ada proses asynchronous seperti timer atau fetch, proses tersebut dipindahkan ke Web API. Setelah selesai, callback akan masuk ke Callback Queue dan dijalankan ketika Call Stack kosong. Mekanisme inilah yang disebut Event Loop. ### Penggunaan * Menjalankan callback. * Mengatur Promise. * Mengelola operasi asynchronous. ### Cara Menjalankan Jalankan program yang berisi kode synchronous dan asynchronous, kemudian perhatikan urutan hasilnya pada console. --- # 9. Timer: setTimeout() dan setInterval() ### Pengertian Timer adalah fitur JavaScript yang digunakan untuk menjalankan kode berdasarkan waktu tertentu. ### Penjelasan * **setTimeout()** menjalankan fungsi satu kali setelah waktu yang ditentukan. * **setInterval()** menjalankan fungsi secara berulang sesuai interval waktu yang diberikan. ### Penggunaan * Membuat countdown. * Menampilkan notifikasi. * Membuat animasi. * Auto refresh. ### Cara Menjalankan Panggil `setTimeout()` atau `setInterval()` dengan menentukan fungsi dan waktu dalam satuan milidetik. --- # 10. Fetch API: Ambil Data dari Server ### Pengertian Fetch API adalah fitur JavaScript yang digunakan untuk mengambil data dari server melalui HTTP. ### Penjelasan Fetch mengembalikan Promise sehingga dapat digunakan bersama `.then()` maupun `async/await`. Data yang diterima umumnya berbentuk JSON sehingga perlu diubah menggunakan `response.json()`. ### Penggunaan * Mengambil data pengguna. * Menampilkan daftar produk. * Mengakses layanan web (Web API). ### Cara Menjalankan Gunakan fungsi `fetch()` dengan alamat URL server, kemudian ubah hasilnya menjadi JSON. --- # 11. Fetch: POST, PUT, PATCH, dan DELETE ### Pengertian POST, PUT, PATCH, dan DELETE merupakan metode HTTP yang digunakan untuk mengirim atau mengubah data pada server. ### Penjelasan * **POST** digunakan untuk menambah data baru. * **PUT** digunakan untuk mengganti seluruh data. * **PATCH** digunakan untuk memperbarui sebagian data. * **DELETE** digunakan untuk menghapus data. ### Penggunaan Digunakan pada aplikasi CRUD (Create, Read, Update, Delete). ### Cara Menjalankan Gunakan `fetch()` dengan menentukan metode HTTP pada properti `method`. --- # 12. Error Handling Fetch dan Network ### Pengertian Error Handling Fetch adalah cara menangani kesalahan ketika mengambil atau mengirim data ke server. ### Penjelasan Kesalahan dapat terjadi karena koneksi internet terputus, alamat server salah, atau server mengalami gangguan. Penanganan error dapat dilakukan menggunakan `.catch()` atau `try...catch` agar aplikasi tetap berjalan dengan baik. ### Penggunaan * Menampilkan pesan kesalahan kepada pengguna. * Mencegah aplikasi berhenti. * Mempermudah proses debugging. ### Cara Menjalankan Tambahkan `.catch()` pada Promise Fetch atau gunakan `try...catch` ketika memakai `async/await`. --- # Contoh Kode **Pada bagian ini letakkan seluruh contoh kode untuk setiap materi secara berurutan, mulai dari Callback Function hingga Error Handling Fetch dan Network.**
